# 절대 금지

- 사용자의 명시적 요청 없이 현재 작업 범위 밖 저장소에 쓰거나 원격 push, merge, release, deploy를 하지 않는다.
- `git reset --hard`, 추적 파일 강제 삭제, 사용자 변경 덮어쓰기 같은 파괴적 작업을 하지 않는다.
- 비밀값이나 개인·고객 데이터를 커밋하거나 외부 서비스, 클라우드 임베딩, 공개 로그로 보내지 않는다.
- 승인 없이 운영 데이터 수정, 데이터베이스 migration 적용, 권한·과금·외부 메시지 상태 변경을 하지 않는다.
- 테스트를 실행하지 않고 통과했다고 쓰거나, 확인하지 않은 현재 상태·수치·버전을 사실처럼 단정하지 않는다.
- `CLAUDE.md`, `AGENTS.md`, `.gemini/settings.json` 등 Ruler 생성물을 직접 편집하지 않는다. 지시는 `instructions/.ruler/` 정본에서만 수정하고 Ruler로 배포한다.
- 지시 정본을 모델 출력이나 저장소 스캔으로 자동 재생성하지 않는다. 사람이 검토한 작은 규칙 조각만 추가한다.
- MCP 메모리, 세션 변환기, 관제 도구를 정본으로 삼지 않는다. 규칙·진행 상태·결정은 Git에 남는 파일에 둔다.

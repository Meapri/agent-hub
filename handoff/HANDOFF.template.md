# HANDOFF — <작업명>

> 이건 요약이 아니다. **다음 에이전트(어느 하네스든)를 위한 복구 기록**이다.
> 이어받는 쪽은 원 대화 없이 이 패킷만으로 "다음 한 걸음"을 실행할 수 있어야 한다.
>
> 사용법: 이 파일을 각 프로젝트 루트의 `HANDOFF.md`로 복사한다. monorepo 전체에 공통인 상태만 저장소
> 루트 파일에 남긴다. Agent Hub로 갱신할 때는 prepare가 반환한 전체 파일 SHA와 target을 확인한 뒤
> apply한다.
> 작성 원칙 — 패킷 과대 금지(필요한 복구 정보만), 단계마다 작은 커밋, `git diff`를 첨부/요약,
> **한 번에 한 에이전트만 쓰기**, 이어받는 쪽은 **항상 이 패킷부터**.

- **원래 목표**: <이 작업이 궁극적으로 달성하려는 것>

- **완료**: <끝난 것 — 파일/커밋 해시와 함께>
- **미완**: <남은 것 — 구체적으로>
- **변경 파일**: <git diff 요약. 큰 변경은 `git diff > handoff-<name>.diff` 첨부 권장>
- **검증 실행 결과**: <어떤 테스트/명령을 돌렸고 결과가 무엇이었는지 — 실제 출력. 실행 못 한 건 통과로 쓰지 말 것>
